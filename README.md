## 🏢 what is codequarter?

codequarter reimagines a codebase as a headquarters.

instead of navigating folders and files, developers can explore a spatial representation of the system and see how different parts of the architecture connect.

## 🧭 how it maps

| code           | quarter        |
| -------------- | -------------- |
| features       | rooms          |
| components     | workspaces     |
| apis           | doors          |
| services       | departments    |
| dependencies   | hallways       |
| infrastructure | utility spaces |

## 🎯 the idea

make unfamiliar codebases easier to understand, explore, and onboard into by turning software architecture into something you can physically navigate.
