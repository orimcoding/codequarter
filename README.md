# codequarter

**your codebase, headquartered.**

codequarter turns software repositories into interactive 3d offices, where features, components, apis, services, and dependencies become physical spaces you can explore.

instead of reading a codebase as a tree of files, codequarter lets you understand how the system fits together spatially.

## concept

* features become rooms
* components become workspaces
* apis become doors and connections
* services and infrastructure become dedicated areas
* dependencies become paths between spaces

the goal is to make unfamiliar codebases faster to understand, easier to explore, and more intuitive to onboard into.
